# datacommons: Client for the 'Google Data Commons API V2'

Access the 'Google Data Commons API V2'
<https://docs.datacommons.org/api/rest/v2/>. Data Commons provides
programmatic access to statistical and demographic data from dozens of
sources organized in a knowledge graph.
